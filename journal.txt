Portfolio Development Journal — Day 1

1. Project Planning & Technology Selection

The first step was to define the purpose of the project and decide how the portfolio website would be developed. The goal is to create a personal portfolio website that can showcase my education, technical skills, projects, certifications, resume, and contact information in one place.

For the initial version, I decided to use HTML, CSS, and JavaScript instead of immediately using a framework such as React. This keeps the project simple and allows me to understand the fundamentals of web development while building the website.

The initial technology stack was defined as:

HTML5 — Website structure and content

CSS3 — Styling and layout

JavaScript — Interactivity and future dynamic features

Git & GitHub — Version control and project management

The project was also planned to be developed gradually rather than trying to complete the entire website at once.
2. Project Architecture & File Organization

A basic project architecture was created to keep the project organized and make it easier to expand later.

The current structure is:

portfolio/
│
├── README.md
├── index.html
│
├── css/
│   └── style.css
│
├── js/
│   └── script.js
│
└── assets/
    ├── images/
    ├── icons/
    └── resume/

The main HTML file acts as the entry point for the website. CSS and JavaScript were separated into their own directories instead of placing everything inside index.html.

An assets directory was also planned for resources such as profile images, project screenshots, icons, and the resume. This structure should make the project easier to maintain as more content is added.

A README.md file was also added to document the project, its technologies, structure, development phases, and future improvements.

3. Initial Website Structure & Implementation

The first version of the website structure was implemented using HTML.

The page currently contains the main sections that will eventually form the complete portfolio:

Home — Introduction and basic personal information

About Me — Educational and professional background

Skills — Technical skills and areas of knowledge

Projects — Projects that I have developed or am currently working on

Contact — Contact information and communication links

Footer — Basic copyright information

Two projects were initially included as placeholders:

Big Data Crop Recommendation System

A data-driven project involving soil and environmental information, with technologies such as Python, Apache Spark, Hadoop, and Hive.

DayLog

A personal journaling and productivity application that is being developed separately.

These projects will be expanded later with descriptions, screenshots, technologies used, GitHub repositories, and other relevant information.

4. Initial Design & Future Development

A basic dark-themed visual design was implemented using CSS. The first styling focuses on establishing the overall layout rather than creating the final polished design.

The initial design includes:

Fixed navigation bar

Navigation links to different sections

Dark background

Highlighted accent color

Hero section

Project cards

Skill cards

Basic buttons

Section spacing

Footer

Smooth scrolling between sections

JavaScript was also connected to the website. At this stage, it only contains basic functionality to confirm that the JavaScript file is correctly loaded.

The website is intentionally still simple. The current version provides the foundation on which the final portfolio can be built.

Planned Future Development

The next stages will focus on:

Improving the visual design and typography

Making the website fully responsive for mobile devices

Adding project screenshots and detailed project information

Adding certificates and resume

Adding GitHub and LinkedIn links

Adding animations and interactive elements

Improving the navigation experience

Testing the website across different screen sizes

Deploying the finished portfolio online

Day 1 Summary

The main achievement of the first development session was establishing the complete foundation of the portfolio project. The technology stack, folder structure, README documentation, basic HTML sections, initial CSS styling, and JavaScript setup are now in place. Future development can focus on improving the design and adding real content without having to restructure the project.
Portfolio Development Journal — Day 2

1. Navigation Bar Development

The portfolio's navigation bar was improved from the basic version into a more structured and professional navigation system. A fixed navigation bar was implemented so that the main navigation remains visible while moving through different sections of the website.

The navigation now contains links to the major sections of the portfolio:

Home

About

Skills

Projects

Contact

The portfolio logo was also made clickable, allowing the user to return to the Home section. CSS hover effects were added to the navigation links to provide visual feedback when the user interacts with them.

A semi-transparent background and blur effect were also introduced to make the fixed navigation blend better with the overall dark theme.
2. Hero Section Implementation

The basic Home section was upgraded into a proper Hero section, which will serve as the first introduction to the portfolio.

The Hero section now contains:

A small introductory text

My name — Akshay K Sasi

My role as an AI & Data Science Student

A short description of my interests

A View Projects button

A Download Resume button

GitHub and LinkedIn placeholders

The section was designed to immediately communicate who I am and what areas I am interested in.

The HTML structure was also improved by introducing classes such as hero, hero-content, hero-intro, and hero-description. This makes the structure easier to style and maintain as the project develops.
3. CSS Styling & Foundation Improvements

The CSS structure was reorganized to support the new navigation and Hero section. The stylesheet was divided into clear sections such as Reset, General Styling, Navigation, Hero, Buttons, Social Links, Projects, Skills, Contact, and Footer.

The main visual improvements included:

Dark overall theme

Green accent color for important elements

Improved typography and spacing

Fixed navigation

Hover effects

Hero content alignment

Styled project and skill cards

Styled primary and secondary buttons

Smooth scrolling between sections

Backdrop blur for the navigation bar

The JavaScript functionality was not expanded yet because the focus of this development session was the HTML structure and CSS foundation.

Day 2 Summary

The main goal of this session was to transform the basic portfolio skeleton into a more recognizable website. The navigation and Hero section are now properly structured and styled, providing the visual foundation for the remaining sections that will be developed next.
